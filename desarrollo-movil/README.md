# Desarrollo Móvil

Ejercicios, prácticas y proyectos del módulo de **Programación Multimedia y Dispositivos Móviles** de 2º DAM.

## Contenido

- `EjerciciosKotlin/`: ejercicios de introducción y práctica con Kotlin.
- `UT2_PY_Clase_T/`: proyecto Android/Gradle con varios módulos de prácticas:
  - `botones`
  - `contador`
  - `contenedores`
  - `formulario`

Los archivos generados por Android Studio y Gradle se excluyen desde el `.gitignore` raíz del repositorio.
