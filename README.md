## Organización

El repositorio se organiza por módulos y, dentro de cada módulo, por unidades, temas o proyectos. Se conserva la estructura propia de las prácticas cuando modificarla podría afectar a su funcionamiento.

## Flujo Git recomendado

Este repositorio se utiliza desde más de un equipo. Para reducir conflictos:

1. Antes de empezar: `git status` y `git pull --ff-only`.
2. Añadir solo los archivos o carpetas relacionados con el trabajo realizado.
3. Revisar `git status` antes del commit.
4. Crear un commit descriptivo.
5. Finalizar con `git push origin main`.

Se evita usar `git add .` de forma automática para no mezclar cambios de distintos módulos.
